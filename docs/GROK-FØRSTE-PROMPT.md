# Prompt til Grok i Open Design

Lim inn **del 1** i designsystemet. Lim inn **del 2** i det første prosjektet. Ikke begge på en gang.

---

## Del 1 — opprett systemet (ingen skjermer)

```
Du er Grok i Open Design. Du bygger et DESIGN SYSTEM, ikke en app.

Les DESIGN.md, tokens.css og SKILL.md i denne mappen. Det er loven til 18. desember 2026.

Oppgave nå:
1. Registrer systemet som «AK Golf Academy».
2. Vis et kit: farger, type (Oswald / Archivo / IBM Plex Mono), BtnPrimary / BtnGhost / BtnDanger, Kicker+Title+Lead, Panel, Status-setninger, tom tilstand med «—».
3. To tomme skall, ingen innhold: AgencyOS 1440 (rail 236 + flate + inspector 372) og PlayerHQ 390 (fire faner, ingen rail).
4. Bruk tokens.css uendret. Radius 2px. Rust #9b2415 er eneste handling.

Ikke:
- Ny palett, ny font, ny nav.
- Tegn Hjem, Stall, Workbench, Live, Team Norway, WANG.
- Foto som bakgrunn i appen.
- Grønn status, lilla, gradient, glass, shimmer.
- Inverter logo (rød prikk blir cyan).

Norsk UI-tekst. Svar med kit + to skall. Stopp.
```

## Del 2 — første prosjekt (etter at systemet er valgt)

```
Design system: AK Golf Academy (allerede valgt). Ikke forhandle tokens.

Bygg ÉN fil: AgencyOS-skall, høy fidelity.
- 1440: topp «AgencyOS», ni mål i rail (Hjem Stall Kalender Workbench Innboks Godkjenninger AgenticOS Analyse Oppsett), flate tom med Kicker «Flate» + Title «Velg en sak», inspector 372 med «Kontekst».
- 390: ingen rail, bunn: Hjem Stall Uke Innboks Mer. Flate samme tom-setning. Inspector som ark.

data-od-id på rail, topbar, surface, inspector.
Norsk. Ingen dummy-dashboard, ingen grafer, ingen foto.

Når skallet er godkjent av meg, neste melding er Hjem (Nå-oppgave + i dag + kø) — ikke før.
```

---

## Del 3 — hvis den begynner å «forbedre» merkevaren

```
Stopp. Ikke redesign. Loven står i DESIGN.md. Fortsett på siste godkjente skall.
```
