# Coach: år → økt

1. Åpne spiller i Workbench. GolfBox-snitt gir A–K (uten alder). 85 = H.
2. Godkjenn eller flytt den stiplede periode-skissen. Publiser år = skall. Ingen økter ennå.
3. Lag program i bank (FYS: økter/uke + varighet + økt 1…n) **før** serien.
4. I en uke: Gjenta → ukedager + slutt + program. Flere serier samtidig.
5. Turneringsuke: hint vedlikehold i kø. Overstyr fritt.
6. Publiser uke: plan / live / lagring er tre statuser.
7. Etter økt: AI-forslag for gjenstående program i Godkjenninger.
