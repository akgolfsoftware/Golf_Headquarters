# Språk og treningsplanlegging — gjennomgang (MASTER)

**Status 22.09.2026 (Anders):** Dette dokumentet er master for valgtreet fra årsplan til øvelse (åtte trinn) og for språkbeslutningene i tabellene. Der det spriker fra [Treningsplanlegging](treningsplanlegging.md) eller [ordboken](ordbok.md), gjelder dette dokumentet. Tomme «Ønsket endring»-felt betyr at dagens valg står inntil Anders fyller inn noe annet.

## 5. Slik planlegges én øvelse

Dette er hierarkiet coachen skal møte når en øvelse legges inn i en økt.

```text
1. Hensikt                Hva slags trening er dette?
   → Fys · Tek · Slag · Spill · Turn

2. Treningsområde         Hva trener spilleren på?
   → Utslag · Innspill · Nærspill · Putting · Fysisk · Spill

3. Sted og miljø          Hvor gjennomføres øvelsen?
   → Range · Treningsområde · Bane, korthullsbane · TM Simulator · Treningsrom · Hjemme

4. Måleutstyr             Hvordan måles øvelsen?
   → Med TrackMan · Uten TrackMan · Annen radar 

5. Gjennomføring          Hvordan skal spilleren trene?
   → Motorikk/læringssteg · Treningsmåte · Oppgave

6. Press                  Hvem ser på, og hvilken situasjon trenes?
   → Alene · Observert · Konkurranse · Turnering

7. Mengde                 Hvor mye skal gjøres?
   → Slag · Putter · Hull · Tid · Serier · Repetisjoner

8. Mål                    Hva skal øvelsen flytte eller oppnå?
```

### Eksempel: Teknikkøvelse

```text
TEK
  → Innspill 100 m
    → Simulator
      → Med TrackMan
        → Lav hastighet
          → Lengdekontroll
            → Observert
              → 30 slag
                → Minst 20 innenfor valgt målområde
```

| Trinn | Dagens forslag | Ønsket ord eller endring |
|---:|---|---|
| 1 | Hensikt / pyramide |  |
| 2 | Treningsområde |  |
| 3 | Sted og miljø |  |
| 4 | Måleutstyr |  |
| 5 | Gjennomføring |  |
| 6 | Press |  |
| 7 | Mengde |  |
| 8 | Mål |  |

## 6. Trinn 1 — Hva slags trening er dette?

| Valg | Betyr | Ønsket navn / endring |
|---|---|---|
| Fys — Fysisk | Utvikle fysisk kapasitet |  |
| Tek — Teknisk | Utvikle bevegelse og teknisk utførelse |  |
| Slag — Golfslag | Utvikle et bestemt golfslag |  |
| Spill — Spill | Bruke ferdigheter i en spillsituasjon |  |
| Turn — Turnering | Forberede eller gjennomføre turneringsspill |  |

Valget beskriver hensikten. Deretter åpner Workbench et eget planleggingsløp for det valget.

> **Viktig prinsipp:** Pyramidevalgene er separate grener. Felter som tilhører Fysisk skal
> ikke vises i eller endre Teknikk. Et valg i én gren skal heller ikke overskrive lagrede valg
> i en annen gren.

### 6.1 Oversikt: hva åpnes etter pyramidevalget?

| Valgt pyramide | Første valg | Parametere som vises | Parametere som ikke vises | Ønsket endring |
|---|---|---|---|---|
| Fysisk | Styrke · Kondisjon · Bevegelighet | Fysiske parametere for valgt område | Motorikk · golfteknisk fokus · TrackMan-parametere |  |
| Teknikk | Utslag · Innspill · Nærspill · Putting | Læringssteg der det gjelder · teknisk fokus · sted · måleutstyr · mengde · mål | Fysiske serier, RIR og intensitetssoner |  |
| Golfslag | Utslag · Innspill · Nærspill · Putting | Slagtype · treningsmåte · sted · måleutstyr · press · mengde · resultatkrav | Fysiske parametere · motorikk som standardvalg |  |
| Spill | Bane · simulator · treningsområde | Spilleformat · situasjon · sted · press · hull/tid · resultat | Fysiske parametere · motorikk |  |
| Turnering | Konkret turnering eller turneringsøkt | Turnering · runde · forberedelse · press · mål · evaluering | Fysiske parametere · motorikk · vanlig blokkvalg |  |

### 6.2 Når coachen velger Fysisk

```text
FYSISK
├── Styrke
│   ├── Øvelse
│   ├── Serier
│   ├── Repetisjoner
│   ├── Belastning / vekt
│   ├── RIR (repetisjoner i reserve)
│   ├── Pause
│   └── Mål
├── Kondisjon
│   ├── Aktivitet
│   ├── Varighet eller distanse
│   ├── Intensitetssone
│   ├── Intervaller og pauser
│   └── Mål
└── Bevegelighet
    ├── Område / øvelse
    ├── Tid
    ├── Repetisjoner
    └── Mål
```

| Avklaring for Fysisk | Beslutning / ønsket endring |
|---|---|
| Skal «Belastning» her bety vekt/motstand, mens treningsmiljø får et annet navn? |  |
| Skal fysisk økt kunne kobles til fysisk plan eller program? |  |
| Skal sted være Treningsrom, Hjemme, Utendørs eller Annet? |  |
| Skal intensitet angis med sone, RPE, puls eller flere av disse? |  |

### 6.3 Når coachen velger Teknikk

```text
TEKNIKK
├── Treningsområde
│   ├── Utslag
│   ├── Innspill
│   ├── Nærspill
│   └── Putting
├── Teknisk fokus som passer valgt område
├── Læringssteg, bare der det er relevant
│   └── Uten ball · Lav hastighet · Automatikk
├── Sted og treningsmiljø
├── Måleutstyr
│   └── TrackMan · Uten TrackMan · Annet · Ikke relevant
├── Treningsmåte
├── Hvem ser på / press
├── Mengde
└── Mål og resultatkrav
```

**Teknikk styres av golfområdet.** Velges Utslag, vises tekniske valg for utslag. Velges
Putting, vises tekniske valg for putting. Fysiske felt som serier, RIR og intensitetssone skal
ikke dukke opp.

| Avklaring for Teknikk | Beslutning / ønsket endring |
|---|---|
| Skal «Motorikk» hete «Læringssteg» i Workbench? |  |
| Skal læringssteg bare vises for Utslag og Innspill/full sving? |  |
| Skal coachen kunne velge ett eller flere tekniske fokus? |  |
| Hvilke TrackMan-parametere skal foreslås for hvert teknisk fokus? |  |

### 6.4 Når coachen velger Golfslag

```text
GOLFSLAG
→ Velg område og konkret slag
→ Velg treningsmåte
→ Velg sted og måleutstyr
→ Velg press
→ Angi antall slag eller putter
→ Angi resultatkrav
```

Her er målet å utvikle selve slaget og utfallet. Læringssteg er ikke et fast krav, men kan
brukes dersom coachen uttrykkelig trenger det.

### 6.5 Når coachen velger Spill

```text
SPILL
→ Velg arena: bane · simulator · treningsområde
→ Velg spilleformat eller situasjon
→ Velg alene · observert · konkurranse
→ Angi hull · tid · oppgaver eller poengsystem
→ Angi spillmål og resultat
```

Spill betyr anvendelse i en spillsituasjon. Det kan foregå i simulator eller på
treningsområde, ikke bare på golfbanen.

### 6.6 Når coachen velger Turnering

```text
TURNERING
→ Velg konkret turnering eller turneringsforberedelse
→ Velg runde / dato / bane
→ Velg forberedelsesoppgave eller spilleplan
→ Angi mål og fokus
→ Gjennomfør
→ Evaluer runden
```

### 6.7 Felles felt etter at grenens innhold er valgt

Disse kan brukes på tvers når de er relevante, men de skal ikke tvinges inn i alle grener:

| Felles felt | Regel | Ønsket endring |
|---|---|---|
| Navn | Alltid |  |
| Dato og starttid | Alltid |  |
| Varighet | Alltid |  |
| Sted | Når det er relevant |  |
| Mengde | Tilpasses grenen |  |
| Mål | Alltid |  |
| Notat | Valgfritt |  |

## 7. Trinn 2 — Hva trener spilleren på?

Treningsområdene skal stå i denne strukturen, ikke som én flat liste.

### Utslag

```text
Utslag
  → Tee Total
```

### Innspill

```text
Innspill
  → 200 m +
  → 150-200 m
  → 100-150 m
  → 50-100 m
```

### Nærspill

```text
Nærspill(Slag innenfor 50 m)
  → Chip
  → Pitch
  → Lob
  → Bunker
```

### Putting

```text
Putting
  → 0–3 fot
  → 3–5 fot
  → 5–10 fot
  → 10–25 fot
  → 25–40 fot
  → 40+ fot
```

### Fysisk

```text
Fysisk
  → Styrke
  → Kondisjon
  → Bevegelighet
```

### Spill

```text
Spill
  → Banespill
  → Simulatorspill
  → Spilløvelse på treningsområde
  → Konkurranseform
```

Spill er ikke det samme som bane. En spilløvelse kan gjennomføres på bane, i simulator eller
på et treningsområde.

| Område | Ønsket navn / valg / endring |
|---|---|
| Tee Total |  |
| Innspill |  |
| Nærspill |  |
| Putting |  |
| Fysisk |  |
| Spill |  |

## 8. Trinn 3 — Hvor gjennomføres øvelsen?

Dette valget beskriver stedet og treningsmiljøet. Det må holdes atskilt fra hva spilleren
trener på.

### 8.1 Hele valghierarkiet for sted og treningsmiljø

```text
STED OG TRENINGSMILJØ
├── Utendørs treningsområde
│   ├── Driving range → Matte · Gress · Overdekket · Åpent
│   ├── Nærspillsområde → Chip · Pitch · Lob · Bunker · Innspill
│   ├── Puttinggreen → Flat · Helling · Kort putt · Lang putt
│   └── Korthullsbane
├── Golfbane
│   ├── Hele banen · Første ni · Siste ni · Valgte hull
│   ├── Ett hull / gjentatt situasjon
│   └── Treningsrunde · Turneringsrunde
├── Innendørs golf
│   ├── Simulator → Spill · Range · Nærspill · Putting · Test · Konkurranse
│   ├── Golfstudio → Nett · Matte · Speil · Kamera · Puttingflate
│   └── Innendørs treningshall
├── Fysisk treningssted
│   ├── Treningsrom · Styrkerom · Kondisjonsområde
│   ├── Bevegelighetsområde · Utendørs · Hjemme
├── Hjemme / eget sted
│   └── Inne · Ute · Puttingmatte · Nett · Speil · Uten utstyr
└── Annet sted
    └── Skole · Treningssamling · Annen klubb · Fritekst
```

### 8.2 Detaljvalg innenfor hvert hovedmiljø

| Hovedmiljø | Konkret sted | Detaljvalg som kan vises | Aktuelle pyramidegrener | Ønsket endring |
|---|---|---|---|---|
| Utendørs treningsområde | Driving range | Matte/gress · overdekket/åpent · målgreen · avstandsmerker · egen/delt plass | TEK · SLAG · SPILL |  |
| Utendørs treningsområde | Nærspillsområde | Chip · pitch · lob · bunker · innspill · green · ulike lies | TEK · SLAG · SPILL |  |
| Utendørs treningsområde | Puttinggreen | Flat/helling · korte/lange putter · hullplassering · treningsstasjon | TEK · SLAG · SPILL |  |
| Utendørs treningsområde | Korthullsbane | Antall hull · valgte hull · utslagssted · spillformat | SLAG · SPILL · TURN |  |
| Golfbane | Hele eller deler av banen | Bane · tee · hull · antall hull · starttid · treningsrunde/turneringsrunde | TEK · SLAG · SPILL · TURN |  |
| Innendørs golf | Simulator | Anlegg · program/bane · virtuell range/spill/test · antall hull · spilleroppsett | TEK · SLAG · SPILL · TURN |  |
| Innendørs golf | Golfstudio | Nett · matte · speil · kamera · puttingflate · tilgjengelig måleutstyr | TEK · SLAG |  |
| Innendørs golf | Treningshall | Stasjon · mål · nett · matte · fysisk område | FYS · TEK · SLAG · SPILL |  |
| Fysisk treningssted | Treningsrom/styrkerom | Tilgjengelig utstyr · treningssone · program · veiledning | FYS |  |
| Fysisk treningssted | Utendørs | Underlag · løype · bakke · distanse · værforhold | FYS |  |
| Hjemme | Inne eller ute | Plass · puttingmatte · nett · speil · fysisk utstyr · uten utstyr | FYS · TEK · SLAG |  |

### 8.3 Valg som følger etter valgt sted

| Etter sted | Mulige valg | Regel | Ønsket endring |
|---|---|---|---|
| Konkret lokasjon | Klubb, bane, simulator, rom eller anlegg | Valgfritt når stedet allerede er kjent |  |
| Delområde | Utslagsplass, green, bunker, hull, treningsstasjon eller fysisk sone | Når stedet har flere områder |  |
| Underlag | Gress · matte · sand · kunstgress · gulv · annet | Når underlaget påvirker øvelsen |  |
| Oppsett | Nett · speil · kamera · mål · kjegler · puttingmatte | Beskriver treningsoppsettet |  |
| Fasilitet | Booket · delt · coachområde · egen plass | Valgfritt |  |
| Forhold | Inne/ute · vær · vind · temperatur · greenhastighet · lie | Bare relevante forhold |  |
| Måleutstyr | TrackMan · annet · uten måleutstyr | Velges i trinn 4, ikke som sted |  |

### 8.4 Forslag per pyramidevalg

| Pyramide | Foreslås først | Fortsatt mulig | Skal ikke påvirke | Ønsket endring |
|---|---|---|---|---|
| Fysisk | Treningsrom · styrkerom · utendørs · hjemme | Treningshall · annet | Motorikk og TrackMan-parametere |  |
| Teknikk | Range · nærspill · puttinggreen · studio · simulator | Bane · hjemme · annet | Styrke, RIR og kondisjonsfelt |  |
| Golfslag | Range · nærspill · puttinggreen · simulator | Bane · studio · korthullsbane | Fysiske parametere |  |
| Spill | Bane · korthullsbane · simulator · treningsområde | Puttinggreen · nærspill · annet | Pyramidevalget skal forbli SPILL |  |
| Turnering | Konkret bane · simulatorturnering | Korthullsbane · annet konkurransested | Pyramidevalget skal forbli TURN |  |

### 8.5 Eksempler

```text
TEK → Innspill 100–150 m → Treningsområde → Driving range → Gress
→ Åpen utslagsplass → TrackMan velges separat i trinn 4

SPILL → Simulatorspill → Innendørs golf → Simulator → Valgt bane
→ 18 hull → Konkurranseformat

FYS → Styrke → Fysisk treningssted → Styrkerom → Tilgjengelig utstyr
→ Fysisk belastning angis i FYS-grenen
```

## 14. Hele hierarkiet samlet

```text
ØKT
└── ØVELSE
    └── 1. Velg hensikt / pyramide
        ├── FYS
        │   └── Fysisk område → egne fysiske parametere → mengde → mål
        ├── TEK
        │   └── Golfområde → teknisk fokus → læringssteg ved behov
        │       → sted → måleutstyr → treningsmåte → press → mengde → mål
        ├── SLAG
        │   └── Golfområde → konkret slag → treningsmåte
        │       → sted → måleutstyr → press → mengde → resultatkrav
        ├── SPILL
        │   └── Arena → spilleformat/situasjon → press → hull/tid → mål
        └── TURN
            └── Turnering → runde/bane → forberedelse → mål → evaluering
```

**Ingen gren arver detaljfeltene fra en annen gren.** Bare relevante fellesfelt gjenbrukes.
