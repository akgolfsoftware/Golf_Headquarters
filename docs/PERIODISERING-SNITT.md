# Periodisering etter snittscore

**Alder er ute.** A–K i `ak-kategori.ts` har «typisk alder» og Junior/Senior i *navn* — det skal ikke styre noe. Formel = kun brutto snittscore. Visningsnavn må vaskes (ikke «Rekrutt Junior»).

## 70 er ikke 70

Norsk junior med snitt 70 på Onsøy/Oleo og Viktor Hovland med snitt 70 på tour er **ikke samme spiller**. Tallet uten **kilde og kontekst** er løgn.

| | Norsk amatør 70 | Hovland 70 |
|---|---|---|
| Kilde | GolfBox / Oleo / NGF | DataGolf / tour |
| Bane | Norske anlegg | Tour-setup |
| Felt | Amatørfelt | PGA |
| A–K | Kan treffe B/C | Tour er et annet spor |

Regel: snitt vises alltid med kilde. GolfBox-snitt og DataGolf-snitt **blandes aldri** i samme A–K-oppslag. Periodisering for academy leser **norsk brutto** (GolfBox). DataGolf er referanse, merket.

Amatør/proff i Meg er **tolkning + tetthet**, ikke aldersskille: proff kan bruke A–K + periodiseringskø; amatør ser enkle økter. Samme 70 tolkes ikke som tour-nivå fordi noen heter Hovland.
