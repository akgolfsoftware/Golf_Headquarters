# Grok 4.6 — trygg arbeidsstart mens Design System v0.1 lages

Denne planen er en underplan til [arbeidslisten](../MASTERPLAN-GJENSTAAENDE.md). Claude Design eier det nye visuelle systemet. Grok 4.6 arbeider lokalt i Terminal på teknisk funksjon, testbarhet og kartlegging som ikke låser farge, font, geometri, navigasjon eller komponentutseende.

## Anbefalt første leveranse

Start med **R-E: den innloggede spillerreisen** gjennom I dag → Plan → øktark → Live → oppsummering → gjenåpning for alle tre eksisterende øktmodeller. Dette er høyest prioritert i arbeidslisten og kan gjøres uten å velge nytt design.

Leveransen skal:

- bruke en separat, tom testdatabase og syntetiske roller;
- bevare TrainingSessionV2, WorkbenchSession og eldre TrainingPlanSession som separate modeller;
- bevise at samme økt, status og tall følger hele reisen;
- prøve egen spiller, tillatt coach, uvedkommende coach/spiller, lagringsfeil og gjenåpning;
- rette tekniske feil som testene avdekker, men ikke redesigne skjermene;
- stoppe før migrasjon, produksjonsdata, betaling, utsending, utrulling eller endring av `vercel.json`.

Hvis testmiljøet ikke er klart, er første uavhengige del å ferdigstille testoppsettet etter [oppskriften for lokal testdatabase](../utvikling/lokal-testdatabase.md), dokumentere nøyaktig blokkering og fortsette med test-fixtures og tilgangstilfeller som ikke krever database.

## Deretter, i denne rekkefølgen

1. Lukk Caddie-køens eier- og fritekstgrense med serverregler og tester. Ikke endre UI-uttrykket.
2. Styrk handlingstilgang og ressursavgrensning for PlayerHQ, AgencyOS, Team Norway og WANG med tillatte og avviste tilfeller.
3. Kartlegg ruter, handlinger, tomme/laste-/feiltilstander og datakilder til skjermregisteret. Ikke foreslå visuelle verdier.
4. Forbered booking-/betalingsreisen med syntetiske data og testmiljø. Ingen reell betaling eller publisering.

## Ikke start før Claude Design-versjon er valgt

- globale tokens, fonter, farger, radius, skygger og avstandsskala;
- ny hovednavigasjon eller flytting av funksjoner mellom flater;
- omskriving av delte UI-komponenter kun for nytt utseende;
- fullføring av PlayerHQ-, AgencyOS- eller AgenticOS-skjermer mot Train-lock eller dagens v2 som visuell fasit;
- sletting av gamle komponenter, CSS eller ruter før deres funksjon og importer er erstattet og prøvd.

## Overlevering til det nye designsystemet

Når Claude Design-versjonen er valgt, leverer Grok et teknisk reisekart: ruter, delte komponenter, serverhandlinger, datamodeller, tilstander og tester. Designimplementeringen kan da bytte presentasjonen kontrollert uten å gjette på funksjon eller slette skjulte avhengigheter.
