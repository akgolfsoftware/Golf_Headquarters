# FYS-program — låst 18.09.2026 02:21

Program lages før kalenderen. Serien peker på programmet.

## Bank

FYS → Styrke | Kondisjon | Bevegelighet. Antall økter/uke + varighet. Økt 1…n: øvelser, serier, reps, hvile, vekt, valgfri kommentar. Hensikt per økt: øke · vedlikehold · restitusjon.

## Kalender

Serie lenker til ferdig program (man=økt1, ons=økt2, …). Turneringsuke: bytt hensikt, ikke slett.

## Live — som en treningsapp (låst)

**Planlagt og faktisk er to kolonner.** Aldri overskriv plan med det du løftet uten at det vises.

- Legg til / fjern serie under økten.
- Endre vekt per serie.
- Reps per serie: plan 4×4 @ 100, siste serie 3 reps @ 100 → lagres **3**, ikke 4. Økten lyver ikke.
- RIR etter serie → AI anbefaler vekt til **neste serie i samme økt**.
- Kommentar per serie eller økt, valgfri.
- Økten ferdig → AI analyserer faktisk logg → forslag i **treningsplanen** (kø) for gjenstående økter. Historikk urørt.

Kondisjon = segmenter (tid/sone). Bevegelighet = minutter. Styrke = serier × reps × kg + RIR.
