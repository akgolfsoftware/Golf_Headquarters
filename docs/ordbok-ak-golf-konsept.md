# AK Golf — staving av appord (del B)

**Oppdatert 15.09.2026.** Del A (fagbegreper, koder, treningsmodell) er slettet — fasiten er
[ordbok-master-trening.md](ordbok-master-trening.md). Denne fila er kun **del B: hvordan
vanlige appord staves i skjermtekst**. Ved konflikt om betydning, koder eller enheter vinner
masteren. Historiske rader her (L-faser, CS, M/PR, gamle avstandsbånd) er ikke gjeldende.

## Endrings-prosess

1. **Endre i canon først** (MasterBrain) hvis det gjelder konsept-verdier — deretter denne fila → `docs/ordbok-master-trening.md` (visning) → `docs/ordbok.json` (regenerer med `npx tsx scripts/ordbok-json.ts`) → kode.
2. Ren UI-tekst: endre i denne fila først, så søk-erstatt i kode:
   ```bash
   grep -rln "gammelt ord" src/ | xargs sed -i '' 's/gammelt ord/nytt ord/g'
   ```
3. Verifiser: `npx tsc --noEmit && npm run build`
4. Commit: `chore(ordliste): "X" → "Y"`
