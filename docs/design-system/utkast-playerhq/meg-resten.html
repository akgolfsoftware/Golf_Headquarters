Hva som er nytt

  • Sikkerhet viser hvordan du logger inn (Google eller e-post og passord), og bare de valgene som gjelder deg. Ingen oppdiktet «sikkerhetsscore» og ingen «kommer snart».
  • Tofaktor i tre steg: skann koden, skriv sekssifret kode, ferdig. Slå av krever ny innlogging.
  • Dataene dine viser hva som er lagret om deg, og laster ned alt som én fil. Lenkes fra Innstillinger, ved «Slett kontoen min».
