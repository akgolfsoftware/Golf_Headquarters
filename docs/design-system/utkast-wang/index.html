Utkast 1Åpne

Det viktigste å ta stilling til

  1. Data Golf for WANG-trenere (pakke 5). Utkastet viser det, etter vedtaket 06.10.
  2. Hvem publiserer uttak til samlinger: trener eller bare sportssjef (pakke 5).
  3. Egen innboks for WANG, eller samme som AgencyOS (pakke 6).
  4. Vurderingspunktene i opptaket (pakke 8) og spørsmålene i utviklingssjekken (pakke 7) må komme fra deg og Team Norway.
  5. Nivåtall A–K per test og landslagsnivå er ikke vedtatt; utkastet viser «—» (pakke 4).

Alle åpne spørsmål, per pakke, står i README i docs/design-system/utkast-wang/.
