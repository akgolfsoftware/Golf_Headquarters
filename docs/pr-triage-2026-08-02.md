på en parent lukket barnet (#165, #168) uten forvarsel. #165 ble gjenåpnet som #249 og merget.
#168s innhold lå allerede i #169s gren, så det kom inn den veien. **Lærdom: retarget barnet til
`main` FØR parent merges — og verifiser at retargetingen faktisk tok.**

**2. Navnekollisjon på Prisma-modell gjorde main rød.** #166/#169 innførte en modell `AiMemory`
(tabell `ai_memories`, spillerminne med pgvector) mens det allerede fantes en `AiMemory`
(tabell `ai_memory`, nøkkel/verdi per bruker). Prisma nekter duplikatnavn → `prisma generate`
feilet → hele CI falt. Rettet i main samme kveld: den nye heter nå `AiSpillerminne`, tabellnavn
urørt, ingen kodeendring (all tilgang går via rå SQL). **Lærdom: to grener som begge legger til
Prisma-modeller kan gi grønn CI hver for seg og rød CI etter merge — schemaet er delt tilstand
som PR-gaten ikke ser før sammenslåingen.**
