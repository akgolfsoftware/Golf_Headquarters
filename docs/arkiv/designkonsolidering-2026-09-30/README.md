# Historiske innganger før konsolideringen 30.09.2026

Dette er urørte kopier av aktive dokumenter som inneholdt utgående eller motstridende føringer. Filstrukturen viser opprinnelig plassering; relative lenker i kopiene er historiske og skal ikke brukes som aktive instruksjoner.

Gjeldende inngang: [designarbeidet](../../design-system/ak-hq-designarbeid.md). [Kildekontrollen](../../design-audit/precision-training-motor-2026-09-30.md) forklarer endringene. Arkivet omfatter dokumentasjon, ikke sletting av appfunksjoner. Avhengige Train-lock-/Paper-filer er foreløpig beholdt der koden og kontrollskriptene forventer dem.
