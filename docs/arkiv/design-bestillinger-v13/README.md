# Arkiverte design-bestillinger (v13-systemet)

Arkivert 2026-07-27.

Disse tre bestillingene ble skrevet 6.–7. juli 2026 mot **v13-designsystemet**
(forest #005840 / lime #D1F843, Familjen Grotesk + Inter + JetBrains Mono,
Claude Design som design-kilde).

Det designsystemet ble **avviklet 25. juli 2026** — designlåsene er tømt, og et nytt
komplett designsystem utvikles i Open Design. Bestillingene er dermed utdaterte både i
designretning og i vokabular (de bruker gamle navn som «Miljø», «Press» og «Teknisk»,
som nå heter Arena, Belastning og Teknikk).

| Arkivert fil | Innholdet er nå dekket av |
|---|---|
| `D1-workbench-live.md` | D2 — live-økt og Workbench-palett |
| `D4-booking-forelder.md` | D3 — booking (spiller + admin) og foreldreportal |
| `D6-runde-logg.md` | D3 — runde-logg under Analyse |

Gjeldende bestillinger ligger i `docs/design-bestillinger/`:
- **D2** — Workbench, planlegging, årsaksdiagnose, økt-skjermer
- **D3** — alle resterende flater

Beholdt for historikk: datakontraktene i D6 (slag-for-slag-føring) er fortsatt korrekte
og kan brukes som referanse selv om designdelen er utdatert.
