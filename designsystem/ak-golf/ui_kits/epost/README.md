# E-post

Tre maler, alle 600 px bredde og bygget med tabell-layout, inline stiler og
web-trygge fallbacks — Archivo Narrow og IBM Plex Mono lastes fra Google Fonts,
og der de ikke støttes faller malen til Arial og Courier New.

| Fil | Hva det er |
|---|---|
| `nyhetsbrev.html` | Månedlig. **Én sak, ikke fem.** Én lenke til slutt |
| `transaksjon.html` | Bekreftelse, påminnelse og kvittering i samme mal |
| `signaturer.html` | E-postsignatur per variant |

**Regler**
- Emnefeltet er én konkret ting, aldri «Nyhetsbrev mars».
- Avsenderen er **Anders**, ikke «Teamet i AK Golf».
- Ingen bilder som bærer informasjon — bildene kan være blokkert.
- Avmelding nederst, uten å gjøre det vanskelig.
- Krøllparenteser `{fornavn}` er felter som fylles automatisk.
