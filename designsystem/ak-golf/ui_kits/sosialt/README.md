# Sosiale medier

Seks innleggstyper i tre formater. Teksten er hentet ordrett fra
`guidelines/tekstkonsept.md` § 3 — malene er formen, ikke innholdet.

| Innleggstype | Regel fra tekstkonseptet |
|---|---|
| Fremgangstall | Tallet må være målt. Aldri rundet oppover, aldri «opptil» |
| Slik leser du tallet | TrackMan-parameteren på engelsk, forklart på norsk etter |
| Før og etter | Begge tall fra samme måleoppsett |
| Tips fra coach | Skal kunne brukes uten å kjøpe noe |
| Turneringsresultat | Legg ut svake runder også |
| Påmelding åpen | Si hva som faktisk er ledig |

**Formater:** kvadrat 1080 × 1080 · stående 1080 × 1350 · story 1080 × 1920.
Malene i `kvadrat.html` er vist i halv størrelse (540) for at kortet skal kunne
leses; verdiene skalerer.

**Regler**
- Logoen står nede til høyre, med klaringssone. Aldri over et bildeparti som
  gjør ballen utydelig.
- Ett tall, ett budskap, ett instrumentelement per innlegg.
- Ingen emoji, ingen utropstegn, ingen hashtag-rekker.
