# Dokument

Det som sendes som PDF: brevark, tilbud og sportsplan. A4 (794 × 1123 px ved
96 dpi), satt for utskrift på ubestrøket papir.

| Fil | Hva det er |
|---|---|
| `brevark.html` | Brevark med topp, adressefelt, brødtekst og bunn |
| `tilbud.html` | Tilbud med pris, hva som inngår og gyldighet |

**Regler**
- **Rutenettet står ikke i tekstpartiet.** Målestokk langs venstremargen i
  stedet — se readme.md § 6.2.
- Brødtekst 15 px (≈ 11 pt) med linjeavstand 1,5. Ikke under.
- Prisen står i mono, med hva den gjelder, og uten «fra».
- Ingen vitnesbyrd, ingen logoer fra WANG, GFGK eller Team Norway — de er
  relasjoner, ikke produkter.
