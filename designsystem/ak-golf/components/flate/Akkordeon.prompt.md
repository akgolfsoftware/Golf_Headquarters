Akkordeon for spørsmål foreldre faktisk stiller.

```jsx
<Akkordeon apenIndeks={0} poster={[
  { tittel: 'Hva koster kartleggingsøkta?', innhold: '90 minutter til vanlig timepris. Du går derfra med en skriftlig plan.' }
]} />
```

Titlene er spørsmål i klartekst, ikke temaord. Svaret sier prisen og tida hvis spørsmålet handler om det.
