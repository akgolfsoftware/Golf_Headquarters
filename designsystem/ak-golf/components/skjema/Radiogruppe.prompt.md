Radiogruppe for to til fem valg. `note` bærer presiseringen, så hovedteksten kan være kort.

```jsx
<Radiogruppe merkelapp="Hva gjelder det?" valg={[
  { verdi: 'junior', tekst: 'Juniorgruppe', note: 'U10, U12, U14 eller U16' },
  { verdi: 'voksen', tekst: '1:1-coaching', note: 'Kartleggingsøkt først' }
]} />
```
