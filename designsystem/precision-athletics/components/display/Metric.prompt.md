A measured number: sans label, mono tabular value, mono unit, optional source line.

```jsx
<Metric label="Carry 7-jern" value="152,4" unit="m" delta="+2,1" deltaDir="up" meta="TRACKMAN · 24.09" />
<Metric label="Putt i fot" value={null} meta="Ingen runder denne uken" />
```

- Norwegian decimal comma. Empty = "—".
