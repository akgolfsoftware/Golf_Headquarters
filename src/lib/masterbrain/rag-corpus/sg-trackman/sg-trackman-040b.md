| Norsk term | Engelsk term | Definisjon |
| --- | --- | --- |
| Slag spart | Strokes Gained (SG) | Måling av relativ ytelse: positiv = bedre enn referansen |
| Forventede slag | Expected strokes / Baseline | Gjennomsnitlig antall slag for å fulføre hullet fra en gitt posisjon |
| Baseline | Baseline | Se «forventede slag» |
| Utslag | Tee shot | Første slag på et hull |
| Slag spart: Utslag | SG: Off-the-Tee (OTT) | SG-kategori for tee-slag på par-4 og par-5 |
| Slag spart: Innspill | SG: Approach (APP) | SG-kategori for innspillsslag (>100 yards og par-3 tee-slag) |
| Slag spart: Rundt greenen | SG: Around-the-Green (ARG) | SG-kategori for slag innen 30 yards fra greenkanten |
| Slag spart: Putting | SG: Putting (PUTT) | SG-kategori for alle slag på puttinggreenen |
| Tee-til-green | Tee-to-Green (T2G) | OTT + APP + ARG - alt ikke-putting |
| Totalt slag spart | SG: Total | T2G + PUTT |
| Ligge | Lie | Ballens posisjon/underlag (fairway, rough, sand, etc.) |
| Fairway | Fairway | Klippet spilleområde mellom tee og green |
| Rough | Rough | Uklippet eller lengre gress utenfor fairway |
| Bunker / sand | Sand / Bunker | Sandkubbe |
| Recovery | Recovery | Stilling fra trær, hinder eller «unplayable» |
| Green | Green (putting green) | Puttingflaten med hullet |
| Proximity | Proximity | Avstand fra hullet etter et slag |
| Dispersion | Dispersion | Spredning av slagmonster; standard-avvik av proximity |
| Slagmønster | Shot pattern | Ellipse av mulige slagutfall (85-90% av slag) |
| Spindeldiagram | Radar chart | Fleraksle-visualisering av SG-kategorier |
| Handicap | Handicap / Handicap Index | Spillerens ferdighetsnvå (WHS-system) |
| Scratch | Scratch | 0 handicap — referansenivå i SG-analyser |
| Klubbhastighet | Club speed | Lineær hastighet av køllehodet rett far impact |
| Angrevsvink | Attack angle | Opp- eller nedadbevegelse av køllehodet ved impact |
| Klubbbane | Club path | Inn-til-ut eller ut-til-in bevegelse av køllehodet ved impact |
| Kølleflate | Face angle (Club face) | Retningen kølleflaten peker ved impact |
| Flate-til-bane | Face to Path | Vinkeldifferansen mellom Face Angle og Club Path |
| Dynamisk loft | Dynamic loft | Vertikalvinkelen av kølleflaten ved impact |
| Spinloft | Spin loft | Vinkelen mellom køllens bevegelsersretning og kølleflaten ved impact (= Dyn. Loft - Attack Angle) |
| Svingplan | Swing plane | Vertical vinkel på planet køllehode beveger seg i |
| Svingretning | Swing direction | Horisontal retning av svingbasen relativ til målinja |
| Lavpunkt | Low point | Laveste punkt i svingbuen |
| Impact-høyde | Impact height | Vertikal treffposisjon på kølleflaten |
| Impact-offset | Impact offset | Horisontal treffposisjon på kølleflaten (hæl/tå) |
| Ballhastighet | Ball speed | Ballens senterhastighet etter impact |
| Smash faktor | Smash factor | Ratio: Ball Speed ÷ Club Speed |
| Startvinkel | Launch angle | Vertikal vinkel ballen tar av ved |
| Startretning | Launch direction | Horisontal vinkel ballen tar av ved |
