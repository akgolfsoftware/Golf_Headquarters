* * *

Putting Klubbdata

| Parameter | Definisjon |
| --- | --- |
| Club Speed | Hastigheten til putterhodet umiddelbart før impakt |
| Backswing Time | Tid køllehodet reiser bort fra ballen |
| Stroke Length | Avstand putteren er dratt tilbake i baksvingen |
| Forward Swing Time | Tid putteren reiser mot ballen til impakt |
| Tempo | Backswing Time ÷ Forward Swing Time |
| Dynamic Lie | Vinkel på skaftet relativt til horisonten ved impakt |
| Attack Angle | Opp- eller ned-bevegelse av putterhodet ved impakt |
| Club Path | Inn-til-ut eller ut-til-inn putterbane ved impakt |
| Face Angle | Retningen putterflaten peker ved impakt (viktigste putting-parameter) |
| Face to Path | Forskjellen mellom Face Angle og Club Path |

Putting Balldata

| Parameter | Definisjon |
| --- | --- |
| Launch Direction | Horisontal vinkel ball starter relativ til mål-linjen |
| Ball Speed | Innledende ball-hastighet etter å ha forlatt putterflaten |
| Skid Distance | Avstand ballen spretter/glir før den ruller |
| Roll Speed | Hastighet på det punktet ballen begynner å rulle riktig |
| Speed Drop | Prosentvis drop fra ball-hastighet til roll-hastighet |
| Roll % | Rullmengde av total puttelengde |
| Effective Stimp | Hastigheten til individuelle putter basert på gjennomsnittlig rullbremse |
| Side | Total sideavstand fra mål ved inngangshastighet |
| Break | Total horisontal bevegelse fra ballens startretning |
| Distance | Total rett linjeavstand fra startpunkt |

Putting Green-data

| Parameter | Definisjon |
| --- | --- |
| Effective Stimp | Individuell putt-basert greenhastighets-beregning |
| Stimp(Flat) | Generell greenhastighet basert på gjennomsnittlig rullbremse |
| Elevation | Høydeforskjell fra ball-start til inngangshastighet-punkt |
| Slope % Side | Gjennomsnittlig horisontal helning av overflaten |
| Slope % Rise | Gjennomsnittlig vertical helning av overflaten |

### Nøkkelputte-innsikter fra Trackman-forskning: - Face Angle ved impakt er den mest

kritiske putteparameteren — putterflaten bestemmer 85%+ av startretning i putting (analogt med driver-full-sving-forholdet) - Skid Distance: På en typisk 10-fot-putt glir ballen (sklir) de første 10–20% av avstanden før rulling-Tempo: De fleste Tour-proffgolfere har et konsistent bakosving-til-fremosving-forhold på ca. 2:1 (baksvingen tar dobbelt så lang tid som nedsvingen) - Launch Direction: Sterkt korrelert med Face Angle — putterflaten må være kvadrert ved impakt for at ballen skal starte på linjen
