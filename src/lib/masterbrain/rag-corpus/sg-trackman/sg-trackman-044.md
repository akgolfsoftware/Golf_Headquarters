**D-Plane:** Face to Path = Face Angle-Club Path Lateral curve (Driver ~270y): 9–12 yards per 1° F2P. Elite: ±1–1.5° varians. **Smash Factor:** Smash Factor = Ball Speed / Club Speed PGA: 1.49+.

## Gear Effect:

Horisontal: s approx 16.4 \* Vb \* x (sidespin RPM) Vertikal: s approx 25 \* Vb \* y (backspin change) **Spin Loft:** Spin Loft = Dynamic Loft-Attack Angle
