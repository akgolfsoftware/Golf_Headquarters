# Under økt — korriger uten å overbelaste

Når spiller sier «den går høyt og høyre»:
1. Bekreft observasjon kort
2. Én P-posisjon: «Sjekk venstre albue ved P7 — er den inn mot kroppen?»
3. Én justering: «Prøv 5 knock-down med halv hastighet»
4. Ikke introduser ny drill midt i sett uten å avslutte forrige fokus
