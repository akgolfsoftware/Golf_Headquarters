# Til godkjenning

Arbeidsmappe for batcher som Anders skal godkjenne.

Dette er ikke fasit. Elementer her kan ha foreslått AK-formel, men må ikke brukes
av agenter før de er flyttet til `ovelsesbank/godkjent/` med:

- `status: "GODKJENT"`
- `godkjentAv: "Anders Kristiansen"`
- `godkjentDato`
- gyldig AK-formel v2

Første puttingbatch ble godkjent 2026-09-26 og flyttet til
`ovelsesbank/godkjent/putting.json`.

Neste arbeidsmål: ta en ny liten batch fra `ovelsesbank/kandidater/`, foreslå
AK-formel v2 og fasilitetsprofil, og la Anders godkjenne/endre/avvise.
