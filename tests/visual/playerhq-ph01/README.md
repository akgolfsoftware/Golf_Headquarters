# PH-01 visuell kontroll

Lokal komponentprøve for valgt PH-01 v1.0. Den bruker faktisk React-komponent og syntetiske data, uten miljøfiler, database eller eksterne kall.

Kjør fra prosjektroten:

```bash
node tests/visual/playerhq-ph01/screenshot.mjs
```

Resultatet skrives privat til `/private/tmp/ak-hq-ph01-visual-20260921/`: 20 appbilder, 20 HTML-referanser, 20 diffbilder og `resultat.json`.
